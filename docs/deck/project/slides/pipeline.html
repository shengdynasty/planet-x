How it works

Five steps from sky to candidate

1

Fetch

Every SPHEREx exposure of a patch, as cutouts from NASA/IPAC IRSA

2

Match

Pair epochs taken at the same wavelength, then align them

3

Detect

Flag sources that moved, appeared, vanished or brightened

4

Identify

Cross-match against JPL’s known asteroids and comets

5

Vet

What’s left is a candidate: check its shape, motion and spectrum

Detection uses a 5-sigma threshold to flag a source, but only a 3-sigma counterpart to count it as still there, which cuts false appear/vanish pairs. Anything left after the known-object match is a candidate, never a detection.
